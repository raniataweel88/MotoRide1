# 🏍️ Motoride

**Motoride** is a platform built for motorcycle enthusiasts.  
It provides an all-in-one experience including buying and selling motorcycles, showcasing gear and apparel, and booking maintenance services online.

---

## ✨ Features
- 🛒 Online store for motorcycles, accessories, and apparel.  
- 📅 Booking system for motorcycle maintenance.  
- ⭐ Customer reviews and ratings.  
- 🔍 Advanced product search and filtering.  
- 📱 Responsive design for both desktop and mobile.  

---
## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript, jQuery ,ajax
- **Backend:** ASP.NET Core 7 / API  
- **Database:** SQL Server  
- **Version Control:** Git & GitHub
